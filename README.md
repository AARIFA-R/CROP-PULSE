# 🌱 Plant Health AI

An AI-powered plant disease detection system that analyzes leaf images to identify the **plant type, disease, and disease severity percentage**.

### ✨ Features

* 🌿 Plant/leaf identification
* 🦠 Disease detection
* 📊 Severity estimation in percentage
* 🔍 Diseased-region segmentation using **U-Net**
* 🧠 Explainable AI using **Grad-CAM**
* 📷 Live camera capture & image upload
* 👤 Separate dashboard for daily users
* 👨‍🌾 Farmer dashboard with bulk image analysis
* 💡 Disease-specific mitigation recommendations
* 📈 Farmer analytics and reports
* 🔐 Firebase authentication and secure data storage
* 🌐 Multilingual support

### 🛠️ Technologies

**React • TypeScript • Firebase • PyTorch • U-Net • Grad-CAM • FastAPI • OpenCV**

### 🎯 Goal

To provide a simple and intelligent solution for **early plant disease detection, severity assessment, and effective crop-health management**.
